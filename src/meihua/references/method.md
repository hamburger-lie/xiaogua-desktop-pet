# 起卦与计算规则

## 数字映射

先天八卦数：乾1、兑2、离3、震4、巽5、坎6、艮7、坤8。数字除以 8，余 0 作 8。

动爻：总数除以 6，余 0 作第六爻。爻从下往上数，初爻为 1，上爻为 6。

五行：乾兑属金，离属火，震巽属木，坎属水，艮坤属土。

## 四种正式模式

### 1. 现代问题指纹法（默认无数字输入）

当用户没有指定算法、数字或已有卦象时，优先用 `personalized-time`，输入：

- 用户本次核心问题的原文
- 提问当下的当地日期与时间，至少精确到秒并带时区偏移；运行环境能提供更高精度时保留小数秒
- 用户确认的城市或时区名称

引擎将三项显式输入规范化后以 SHA-256 生成稳定指纹，再从指纹的不同区段独立取得上卦、下卦与动爻数。相同输入可复算；问题文字、时间或地点任一变化都会改变指纹。这是为避免多人同一时辰得到完全相同结果而采用的现代个性化约定，不是《梅花易数》原典公式。

多人在同一地点、同一时刻用完全相同文字批量测试时，可让每人临时想到一个字或数字，并用 `--personal-seed` 加入指纹。该项默认不询问，不要求真实姓名、生日或固定身份信息。

不得使用或索取 IP、账号 ID、设备 ID、手机号、精确坐标等隐藏或敏感标识作为起卦参数。地点只使用用户主动提供或明确确认的城市/时区。

### 2. 传统年月日时法

仅当农历信息明确时使用：

- 上卦数 = 年支序数 + 农历月 + 农历日。
- 下卦数 = 上卦数 + 时支序数。
- 动爻数 = 下卦总数。
- 地支序数：子1、丑2、寅3、卯4、辰5、巳6、午7、未8、申9、酉10、戌11、亥12。

原始规则来自《梅花易数》“年月日時起例”。分钟不参与传统公式，只记录用于复现。

### 3. 数字法

- 两个数字：第一个定上卦，第二个定下卦，两数之和定动爻。
- 三个数字：第一个定上卦，第二个定下卦，第三个定动爻。
- 保留输入顺序。先对每个负数取绝对值，再进行加总和取模；0 只能在用户确实选择 0 时保留，取模后按余 0 规则处理。

这是 Skill 的统一可复算约定。若用户坚持另一流派算法，先复述差异，再按用户指定算法计算并标注。

### 4. 手动卦象

输入上卦、下卦和动爻。引擎验证后生成互卦、变卦和体用。无动爻时，不生成体用与变卦，只解释静态本卦。

## 公历时间模式

当用户只有公历日期，可选引擎的 `gregorian-time`：上卦取公历年+月+日，下卦再加时支数，动爻同总数。这是现代实用约定，不是《梅花易数》原文的农历年月日法。回答必须明确标注，不能伪装成传统法。

时支按当地时间：23:00–00:59 子，01:00–02:59 丑，依次每两小时一支，21:00–22:59 亥。

## 互卦、变卦与体用

- 六爻由下往上编号 1–6。
- 下互卦取本卦第 2、3、4 爻；上互卦取第 3、4、5 爻。
- 变卦把动爻阴阳翻转。
- 动爻所在的三爻卦为“用”，另一三爻卦为“体”。
- 体为求测者或主体，用为所问之事或对象。

体用关系：用生体、体用比和通常视为支持；体克用表示可控但较迟；体生用表示投入或耗泄；用克体表示阻力。它们是传统解释规则，不是经验证的因果规律。

## 引擎示例

```bash
python engines/cast_hexagram.py numbers --numbers 17 28 43
python engines/cast_hexagram.py personalized-time --question "我最近的桃花怎么样" --datetime 2026-09-21T11:30:08.123456+08:00 --location 广州
python engines/cast_hexagram.py traditional-time --year-branch 9 --lunar-month 8 --lunar-day 7 --hour-branch 10
python engines/cast_hexagram.py gregorian-time --datetime 2026-09-18T14:35:00+08:00
python engines/cast_hexagram.py manual --upper 巽 --lower 乾 --moving-line 4
```


静卦示例：`python engines/cast_hexagram.py manual --upper 巽 --lower 乾`。传统时间模式只核对输入范围，不负责公历转农历或验证该农历日期是否存在。闰月沿用月序数，日期按用户确认的当地历日；如采用其他流派的换日规则，先确认再计算。
