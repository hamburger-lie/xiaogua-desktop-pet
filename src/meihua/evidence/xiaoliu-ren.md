# 小六壬证据包

小六壬民间传本繁杂。现已核对《萬寶玉匣記》上海鴻文書局1936年本卷下「李淳風六壬時課」书影（PDF第66–67页、卷下二十五–二十六）：六宫顺序、月日时顺数步骤及“三月初五日辰时落小吉”例题有具体传本依据。逐条证据、定位和未证事项见 [xiaoliu-ren-sources.json](xiaoliu-ren-sources.json)；计算细则见 [../references/xiaoliu-ren.md](../references/xiaoliu-ren.md)。此书影不能证明篇题署名即作者，也不能证明预测效验。

## XL-01 六宫结果

- **证据**：最终落宫及完整月、日、时输入；数法对应 `XL-R1`—`XL-R3`。
- **可支持**：按 `XL-R4` 概括传统宫象，再结合现实信息给出条件化的短期节奏、沟通与行动提示。
- **不可推出**：六十四卦、动爻、体用、精确应期或长期命理。

## XL-02 六宫强度边界

| 课宫 | 可表达 | 不可直接表达 |
|---|---|---|
| 大安 | 条件偏稳、适合守住基本盘 | 必然成功 |
| 留连 | 有拖延或反复，先清卡点 | 一定失败 |
| 速喜 | 反馈窗口偏快，及时验证 | 马上有喜事 |
| 赤口 | 沟通摩擦风险，宜书面确认 | 对方恶意或背叛 |
| 小吉 | 适合协作和小步推进 | 必然获利 |
| 空亡 | 前提可能不足，宜重核信息 | 一切落空 |

## XL-03 置信降级

- 用户直接提供农历月日时支但无法验证：计算等级最高为 B。
- 公历已通过时区与农历转换：可为 A，但仍只表示计算可复算。
- 临近换日、闰月口径不明：降为 B 并说明条件。

以上 A/B 只表示输入和计算的可复核程度，不表示传统占断的准确率。闰月、换日、公历转换、产品路由和现代行动建议均为项目约定，不能伪称由1936年传本逐项规定。
