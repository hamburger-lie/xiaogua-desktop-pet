每日一瓜 · 小瓜桌宠  使用协议与隐私说明
版本：2026 年 10 月 9 日

每日一瓜是一个开源的桌面小程序，作者是 hamburger-lie（https://github.com/hamburger-lie/xiaogua-desktop-pet）。
安装和使用它，表示你同意下面的内容。


一、小瓜不收集你的任何信息

  - 不需要注册账号，不需要登录。
  - 没有统计、没有埋点、没有广告，不会把任何东西发给作者或者任何第三方服务器。
  - 作者看不到你问了什么、记了什么，也拿不到你的密钥。


二、你问问题时，会发给谁、发些什么

只有在你主动提问时，小瓜才会联网，而且只连你在「设置 → 连接」里自己选的那家模型厂商
（比如豆包 / 火山方舟、DeepSeek、通义千问等），用的是你自己的 API 密钥。每次会发过去：

  - 你这次问的话；
  - 这个对话里最近的几轮问答（让小瓜记得上下文）；
  - 程序算好的今天的黄历、你的属相（如果你告诉过小瓜）；
  - 「小瓜记得的你」里的条目（称呼、偏好、带日期的计划）；
  - 起卦、查黄历的结果。

这些内容在厂商那边怎么处理，以那家厂商的隐私政策为准。
另外，在设置里点「测试并获取模型列表」时，会向厂商查一下模型列表，并发一条很短的测试消息。
不想联网的话，可以在「设置 → 连接」里打开「离线模式」：离线时小瓜只看黄历、在本地起卦，什么都不发出去。


三、存在你电脑上的东西

全部存在 %APPDATA%\MeiriYigua 这个文件夹里，只在你这台电脑上：

  - config.json：你的设置（属相、大小、快捷键、窗口位置等）；
  - memory.json：「小瓜记得的你」；
  - history\chats\：聊天记录（在「设置 → 关于」里可以关掉「保存对话记录」）；
  - trash\：回收站，删掉的对话和记忆在这里放 30 天，到期自动彻底删除；
  - logs\：运行日志，用来排查问题，可能包含小瓜回答里的个别句子。

你的 API 密钥存在 Windows 凭据管理器里，不写进上面任何一个文件。


四、怎么删除

  - 一条记忆：设置 → 记忆 → 删掉选中的（或「全部忘掉」）；
  - 一段对话：对话列表里删除，回收站里可以「彻底删除」；
  - 全部记录：设置 → 关于 → 删除全部记录（回收站也会一起清空）；
  - 密钥：设置 → 连接 → 清除已存密钥；
  - 卸载：开始菜单「卸载每日一瓜」。卸载不会删你的记录，想一起删的话，手动删掉 %APPDATA%\MeiriYigua 文件夹。


五、其他会用到的系统功能

  - 开机自启：只有你在设置里勾选后，才会在注册表 HKCU\...\Run 里加一项；取消勾选或卸载就会删掉。
  - 按键说话：用的是 Windows 自带的语音输入（Win + H），声音怎么识别由 Windows 处理，以你系统的语音隐私设置为准；小瓜自己不录音。
  - 全局快捷键：只监听你设置的那几个组合键，不记录其他按键。


六、使用须知

  - 黄历和卦是传统文化里的一种看法，只供参考，不预测未来，也不保证结果。
  - 看病、法律、投资、借贷这类事，请找专业的人，不要只凭小瓜的话做决定。
  - 小瓜的回答由你选的大模型生成，可能出错；程序会尽量检查（时辰、卦名等），但不能保证全对。
  - 本软件按「现状」提供，作者不对使用它造成的任何损失负责。
