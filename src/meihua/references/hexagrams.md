## 动爻位置

| 动爻 | 变化位置 | 解释重点 |
|---:|---|---|
| 初爻 | 萌芽与起点 | 看是否适合启动、准备是否充分 |
| 二爻 | 内部执行与直接互动 | 看实际做法、合作和资源使用 |
| 三爻 | 内外转换与高风险段 | 看过度用力、犹豫和进退选择 |
| 四爻 | 接近外部机会或权力中心 | 看承接、试探和位置是否合适 |
| 五爻 | 核心决策与主导位置 | 看领导、资源配置和关键取舍 |
| 上爻 | 发展到极端后的收束 | 看完成、反转、退出或重新开始 |

## 组合方法

1. 用本卦说明当前格局。
2. 用动爻位置确定变化发生在哪一层，不凭空编造未收录的爻辞。
3. 用互卦说明中间过程或隐藏因素。
4. 用变卦说明当前策略持续后的可能趋势。
5. 用体用生克修正“支持、消耗、可控或受阻”的强弱。

最终写成“卦象依据 → 条件性判断 → 可验证行动”，不要只给吉凶标签。

## 方位落地

八卦方位表见 `evidence/meihua.md` MH-04；把它换算到用户实际站位的规则见 MH-06。

卦位本身只给绝对方位，对用户没有可执行性——“东北”要用户自己拿指南针换算，“你的右后方”才是能直接照做的。用户给了站位和朝向就必须做这一步，不能只丢一个方位名。

以「面朝南」为例（正右手边即西）：

| 卦 | 方位 | 面朝南时的用户视角 |
|---|---|---|
| 离 | 南 | 正前方 |
| 巽 | 东南 | 左前方 |
| 震 | 东 | 正左手边 |
| 艮 | 东北 | 左后方 |
| 坎 | 北 | 正后方 |
| 乾 | 西北 | 右后方 |
| 兑 | 西 | 正右手边 |
| 坤 | 西南 | 右前方 |

两条硬约束：

1. 没有用户确认的朝向，只给绝对方位，不编左右前后。
2. `orientation=landmarks_only` 表示正北未核实，此时禁止输出任何罗盘方位，只能说“贴着<已确认地标>那一侧”。

方位属于解释顺序的第 6 层（修正项），不能推翻本卦、动爻、体用和变卦形成的主线，也不证明目标确实在那个方向——它只决定“先看哪一侧”。
