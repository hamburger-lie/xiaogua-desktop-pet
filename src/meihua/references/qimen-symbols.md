# 奇门遁甲门、星、神象义（小瓜解读用）

原文出自《奇门遁甲统宗》（行号指维基文库录文，[来源](https://zh.wikisource.org/zh-hans/奇門遁甲統宗)）：八门、九星取「所主」，八神取「八神类神」。行兵布阵、捕盗刑狱、博戏一类的条目不收（GUARD-07 兵家边界）。「白话」是本项目的现代转述，只作该宫环境与时机的象征提示（QM-03），不是格局吉凶。

《统宗》八神列勾陈、朱雀，下注白虎、玄武；本项目用白虎、玄武（QM-06），故这两神取勾陈、朱雀条。

`companion/charts.py` 按本表给小瓜「象义」；改表时同步跑 `tests/test_charts.py`。
